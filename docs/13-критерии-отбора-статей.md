# 13. Критерии отбора научных статей для базы знаний

Статус: v0.2, 2026-10-21. Источник: запрос капитана (19.10) — сформировать критерии,
по которым ИИ-ассистент отбирает статьи для КБ; материал — статьи и датасеты,
присланные Дианочкой, Анастасией и Фарзоной 18–19.10.

Изменения v0.2 (21.10):
- критерии ниже **исполняются детерминированным модулем** `api/app/enrichment/criteria.py`
  (версия `CRITERIA_VERSION`), а не только человеком при загрузке seed-чанка;
- критерий «Юрисдикция (РФ-приоритет)» **снят** решением команды: источники —
  PubMed (систематические обзоры и метаанализы) и гайдлайны ВОЗ/IRIS; РФ-сегмент
  (клинреки Минздрава, препараты ГРЛС) остаётся отдельной, вручную курируемой
  частью корпуса (docs/08);
- статьи принимаются **только человеком** (ADMIN, approve), гайдлайны ВОЗ
  публикуются автоматически **только при подтверждённой в тексте лицензии**
  CC BY-NC-SA 3.0 IGO;
- как критерии исполняются, как хранятся вердикты и провенанс — docs/15.

## 1. Назначение

База знаний (docs/08) содержит только **проверенный контент**: клинреки Минздрава
(рубрикатор `cr.minzdrav.gov.ru`) и препараты ГРЛС. Научные статьи (исследования)
попадают в КБ только после прохождения критериев ниже — это защищает ассистента от
цитирования устаревших/нерелевантных/слабых источников и отвечает условию кейса
«научная обоснованность: указать источники».

Критерии проверяет детерминированный модуль обогащения (docs/15) на входе внешней
публикации, а не ИИ в рантайме: агент не ходит в сеть, поиск идёт по уже
проиндексированному корпусу. Решение о включении статьи в индекс принимает врач
(ADMIN); автоматика лишь отсекает подтверждённые нарушения (см. §5).

## 2. Критерии

| # | Критерий | Порог | Почему |
|---|---|---|---|
| 1 | **Свежесть** | для внешних статей: `текущий год − год публикации ≤ 5` (реализация — `criteria.freshness`); у гайдлайнов ВОЗ старше 5 лет — предупреждение, а не исключение; клинрека — действующая редакция | медицина меняется; клинреки Фарзоны (шизотипическое расстройство, БАР) действуют до 2026 и пересматриваются в этом году |
| 2 | **Дизайн** | **внешний фид — только SR/MA**: систематический обзор, метаанализ, network MA, umbrella review (`criteria.design`); для ручного РФ-сегмента допустимы РКИ/когорта ≥ 100 пациентов | сила доказательности; приоритет РКИ — запрос капитана («рандомизированное плацебо-контролируемое»), но автоматический отбор PubMed ограничен SR/MA (docs/15 §5) |
| 3 | **Релевантность** | тематика: БДР (F32/F33), ГТР (F41.1), БАР-гипомания (HCL-32), ТРД, коморбидность тревога+депрессия, суицидальный риск | корпус ассистента — тревога/депрессия, ничего лишнего |
| 4 | ~~**Юрисдикция**~~ | **снят 21.10**: РФ-приоритет не применяется к внешним публикациям; шкалы и препараты остаются в отдельном РФ-сегменте корпуса (docs/08) | источники обогащения — PubMed и ВОЗ; РФ-валидация проверяется вручную для клинрек/ГРЛС, а не для статей |
| 5 | **Качество** | рецензируемый журнал; указаны выборка, ограничения, конфликт интересов | воспроизводимость, добросовестность |
| 6 | **Применимость** | результат выражается в действии (скрининг, мониторинг, маршрутизация, НЯ), а не только в знании | ассистент отвечает на вопросы врача/пациента, а не читает лекции |
| 7 | **Этика/ПДн** | анонимизированные данные; лицензия допускает использование в продукте | 152-ФЗ, поверхность ПДн не расширяется (docs/07 §3.5) |

## 3. Примеры прошедших статей (от команды, 18–19.10)

| Статья | Критерии | Вердикт |
|---|---|---|
| Вортиоксетин при коморбидном БДР+ГТР, 8 недель (РКИ, 2025+) | 1,2,3,5 | ✅ пример РКИ |
| ТРД: клинометрический подход — истинная/псевдорезистентность, выбор КПТ/MBCT (обзор, 2025+) | 1,2,3,5,6 | ✅ влияет на маршрутизацию терапии |
| ТРД в реальной практике: рецидивы, коморбидности, самоповреждения (когорта, 2025+) | 1,2,3,5,6 | ✅ влияет на мониторинг |
| Комплексный подход при тревоге+депрессии: пределы медикаментозной стратегии (обзор) | 1,2,3,6 | ✅ для библиотеки/справки |
| Фармаконадзор РФ 2019–2024: профиль НР антидепрессантов (risksafety.ru, Султанова 2025) | 1,4,5,6 | ✅ отечественные данные для НЯ |

Присланные Фарзоной ссылки (РИНЦ/Scopus) — **примеры подходящего типа**, не набор
для немедленной загрузки: каждая проверяется по критериям перед добавлением.

## 4. Что в КБ НЕ попадает

- статьи старше 5 лет (исключение — классика, если без неё корпус неполон и она
  по-прежнему цитируется в действующих клинреках);
- синтетические данные (MentalChat16K — диалоги GPT-3.5: для демо-прототипа ок,
  в КБ как источник — нет);
- нерусскоязычные клинические корпуса (PsihoRo — румынский);
- данные без подтверждённой анонимизации/лицензии (PHQ236March — проверить).

## 5. Реализация

- Критерии §2 исполняет модуль `api/app/enrichment/criteria.py`: по каждому
  критерию — вердикт `met` / `not_met` / `insufficient_info` / `not_checked`,
  пояснение, цитата-доказательство и флаг ручной проверки. Исключает только
  `not_met` жёсткого критерия; неизвестное (`insufficient_info`, `not_checked`)
  не считается недостатком. Полная семантика — docs/15 §6.
- Статьи PubMed всегда попадают в очередь ревью (`candidate`) и индексируются
  только после approve ADMIN. Гайдлайны ВОЗ публикуются автоматически, если
  лицензия CC BY-NC-SA 3.0 IGO найдена в тексте документа; иначе — на ревью.
- Топики `НАУЧНЫЕ-СТАТЬИ` / `РЕКОМЕНДАЦИИ` строит `api/app/enrichment/index.py`
  из реестра `kb_works` (источник истины); Qdrant — производный индекс, чанки
  есть только у `approved`-записей. Статический seed-корпус (`kb_seed.py`,
  РФ-сегмент) остаётся отдельным путём загрузки.
- Payload чанка несёт провенанс: `guideline_id`, `source_title`, `topic`,
  `source_url`, `year`, `license`, `revision`, `work_id`, `text_hash`
  (полный список — docs/15 §2). Публичная схема цитаты не меняется:
  `guideline_id` + `title` + `topic` (коммит `5ffa299`).
- Фильтрация при ретривеле — по `topic` и, персонально для врача, по
  `guideline_id` из `kb_exclusions`; свежесть обеспечивается отбором на входе
  (критерий 1), а не фильтром в рантайме.
- Документ-источник критериев: этот файл; изменения — через PR, ревью медиком
  команды. Исполнение критериев, ревью, эксплуатация и ограничения — docs/15.
